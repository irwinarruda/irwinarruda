I'm a software engineer in Goiânia, Brazil, working mostly in TypeScript and React, with C#/.NET on the back end. I like building what makes other developers' work easier: design systems, CLIs, build tooling and, lately, guardrails for coding agents.

Much of my work now is making coding agents reliable inside a team. The guardrails are the ordinary ones, applied strictly: integration tests, linting, type checks, CI and automated code review, plus the specs and skills that teach an agent the codebase.
